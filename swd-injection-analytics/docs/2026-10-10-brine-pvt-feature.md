The human's “Do it” authorized an interactive gas-free water/brine pressure sweep, temperature and salinity controls, charts/tables, documented methods, pyResToolbox reference checks and downloads. Open **Water / brine PVT** in the navigation. The new page works without selecting a dataset. Supply a case name, minimum/maximum **absolute psia**, temperature **°F**, **NaCl wt%**, and 2–101 pressure points. The calculation includes both exact pressure endpoints. It displays four separate property charts and a numerical table: Bw (rb/STB), density (kg/m³ and lb/ft³), viscosity (cP) and compressibility (1/psi). Scientific notation keeps compressibility visible. Chart axes show the actual property range rather than imply a zero baseline.

Any input edit clears visible results and disables exports. Missing/non-finite values, reversed/equal pressure bounds, out-of-range inputs, fractional point counts and empty names cannot yield results. Changing the active source does not change this independent fluid case. It is explicitly **not coupled to constant-J capacity**.

## Scientific/source decision

Inspection found that the inherited Nexus Bw reference rises with pressure, opposite to the carried pyResToolbox anchors. Its historical 5% comparison tolerance did not detect that opposite slope. The old engineering/vendor code and historical fixtures were preserved; this feature does not claim to repair or validate them.

The new browser calculation adapts the actual installed `brine_props(..., ch4_sat=0)` source and its IAPWS-IF97 Region 1 freshwater density helper. Fresh reference values were generated by the already installed absolute interpreter through `node tmp/pvt-feature/capture-reference.mjs`, with `-B`/bytecode writing disabled. No PATH Python/py command, package installation or Python web runtime is involved.

Source conventions are preserved and disclosed: salinity is NaCl mass percent, **not mg/L TDS**; the source density tuple is numerical **g/cm³**, explicitly converted for display; freshwater standard density uses 15 °C / 0.1013 MPa, while the saline standard integral uses 0.1015 MPa; viscosity retains the original 273 K offset; compressibility retains the source 145.038 psi/MPa conversion. Compressibility follows the source Spivey equation and **is not the derivative of the IAPWS-adjusted density**.

Application bounds are **100–10,000 psia, 60–250 °F, 0–20 NaCl wt%**. These are bounded demonstration limits, not full correlation-domain or field validation. Methane saturation is zero. Dissolved CO₂, mixed-ion brines, phase prediction, hydraulics, transient behavior and calibration are excluded.

## Remaining acceptance blockers

- The inherited Nexus Bw pressure trend remains incorrect and is visibly disclosed. The new source-checked method is separate; it does not silently repair old correlation behavior.
- Extreme finite values can still overflow the older calculation engine. Non-finite display/export containment is not a numerical-method fix.
- The general exhibit API can accept contradictory bundles. Actual PVT browser exports are checked, not API-wide consistency.
- Stored ZIP method-0 entries with **zero local sizes and streaming descriptors** remain an inherited parser compatibility limit; comprehensive decompression/dependency review remains open.
- Published study example **A6**, SWD-10 wellbore hydraulics, broader SWD-12 sensitivity/model choices and SWD-11 transient/calibrated capacity remain incomplete. PVT properties alone do not establish sustainable disposal capacity.
- The sandbox-denied server gate and the visual/accessibility coverage limits above remain open.

The earlier existing-producer demand omission and typed spreadsheet error/archive-count defects have bounded correction evidence in their dated reports and current regression tests. Those repaired defects are not relabeled as unresolved; their safeguards remain intact. This feature does not claim full plan or PRD acceptance.
