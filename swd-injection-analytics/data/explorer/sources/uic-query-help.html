How To About

This screen is accessed by selecting the UIC Data Query option from the Expanded Web Access Menu. Search for wells by:

  • Well Type
  • District
  • Oil Lease Number
  • Gas Well Id Number
  • County
  • Field
  • Operator
  • UIC Number
  • Original Authority Date

  • Top Injection Zone
  • Bottom Injection Zone

  • UIC Query results

UIC Search by Well Type

Well type refers to oil wells, gas wells, or both. Selecting Oil Wells results in a list of Oil Wells. Selecting Gas Wells produces a list of Gas Wells. Selecting Both results in a list of Oil and Gas Wells. A flag indicates if the well is a Gas Well or an Oil Well.

  1. Select Oil Wells, Gas Wells, or Both by clicking on the corresponding radio button.
  2. Click on the Submit button to view a list of UIC wells based on the selection. The system displays the results. Note: The system will not display more than 10,000 records. It may be necessary to refine your search by entering more criteria.

Search by Oil Lease Number

Entering an Oil Lease Number or Gas ID Number will result in a list of UIC oil wells that are located in the selected lease.

  1. Select Lease Type (Oil, Gas or Both) at the top of the screen.

  2. Select District Code. (This is required when searching by Oil Lease Number.)

  3. If you know the Oil Lease Number , enter it in the corresponding field and proceed to Step 5.

  4. If you do not know the Lease number, click on the Search for Lease button and use the Lease Query page to find the lease. The proceed to Step 5.

  5. Click on the Submit button. The system displays a list of UIC oil wells in that lease in the results table .

 

Search by Gas Well Id Number

Entering an Gas Well ID Number results in a list of UIC gas wells that are located in the selected lease.

  1. Select Lease Type (Gas Wells) at the top of the screen. (This is required when searching by Gas Well ID.)

  2. Select District Code. (This is required when searching by Gas Well ID.)
  3. If you know the Gas Well ID, enter it in the Gas Well ID No. field and proceed to Step 5.

  4. If you do not know the Lease number, click on the Search for Lease button and use the Lease Query page to find the lease. The proceed to Step 5.

  5. Click on the Submit button. The system displays a list of UIC gas wells in that lease in the results table .

 

Search by County

Entering a county will result in a list of UIC wells located in the selected county.

  1. Select the desired County from the drop down menu.

  2. Click on the Submit button. The system displays the results. Note: The system will not display more than 10,000 records. It may be necessary to refine your search by entering more criteria.

Search by Field

Entering one or more Fields results in a list of UIC Wells located in the selected Field(s).

  1. Click on Search for Field button to use the Field Query screen to search for field. Once you locate the fields, click the Submit button in the Field Query screen and the system returns the Severance Query screen with those fields populated in the Fields box.

  2. Click on the Submit button. The system displays the results.

 

Search by Operator

Entering an Operator(s) results in a list of UIC wells assigned to that Operator(s).

  1. Click on Search for Operator button to use the Operator Query screen to locate Operators you wish to query. Once you find those Operators, click the Submit button in the Operator Query screen and the system returns the Severance Query screen with those Operators populated in the Operator field.

  2. Click on the Submit button. The system displays the results.

 

 

Search by UIC Number

Entering a UIC Number will display the UIC Well assigned to the UIC Number.

  1. Enter the UIC Permit Number.                           

  2. Click on the Submit. The system displays the results.

 

 

Search by Original Authority Date

This search allows you to find a list of UIC wells that were permitted during a specific data range.

  1. Enter the start date for the date range in the From box. (Proper format for dates is MM/DD/YYYY.)                   

  2. Enter the end date for the date range in the To box.               

  3. Click on the Submit button. The system displays the results. Note: The system will not display more than 10,000 records. It may be necessary to refine your search by entering more criteria.

 

 

Search by API Number

Entering an API Number results in a list of UIC Wells assigned to the API Unique Number.

  1. Enter the API Number.

  2. Click on the Submit button to view the corresponding UIC well assigned to the API Number. The system displays the results.

 

 

Search by Top Injection Zone

This allows you to search by the depth the top of the permitted injection zone by entering a depth range.

  1. Enter the lowest depth in the text box marked 'Between'.                   

  2. Enter the highest depth in the second box.             

  3. Click on the Submit button. The system displays the results. Note: The system will not display more than 10,000 records. It may be necessary to refine your search by entering more criteria.

 

Search by Bottom Injection Zone

This allows you to search by the depth the bottom of the permitted injection zone by entering a depth range.

  1. Enter the lowest depth in the text box marked 'Between'.                   

  2. Enter the highest depth in the second box.             

  3. Click on the Submit button. The system displays the results. Note: The system will not display more than 10,000 records. It may be necessary to refine your search by entering more criteria.

 

Search by H-1 Number

This allows you to search for UIC wells by the H-1 project number assigned to the well. Note: If an H-1 Number is entered, a W-14 Number cannot be entered.

  2. Click on the Submit button. The system displays the UIC well that corresponds to that H-1 number.

Navigating and Sorting

The results table may contain multiple results spread over several pages. To navigate the results table:

  • Use the "Next" and "Previous" links to move forward and back through the pages of results.

  • Click on the Page number link to view a particular results page.

  • Select how many results are displayed per page by selecting an option from the Page Size dropdown. The default is ten items per page.

  • Sort the query results by clicking on any of the column headers.

 

 

 

Lease Detail - Using the Tabs

Each result in the UIC Query Results table will have an API number link, and a Lease Number link. When either the API Number link or the Lease Number link is selected, the Lease Detail page is displayed. The UIC link displays the UIC Detail page.

At the top of the Lease Detail page are Tabs that access more detailed information about the particular well. If the title of a tab is underlined, that indicates that the tab is "active" and more information is available through the tab. Using the tabs makes it possble to see this information without performing another query for the Wellbore, P4, etc. Within these pages are links that can be used to drilldown even farther.

The information that can be accessed through the Lease Detail screen for a UIC query is:

  • UIC Tab
    • UIC Detail
  • Wellbore Tab
    • API Number
  • Severance Tab
    • Lease
  • P4 Tab
    • Lease
  • Inactive Well Tab
    • Extension Status
  • Operator Tab
